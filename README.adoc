A Java (25) + LWJGL/OpenGL reimplementation of https://www.xpilot.org/[XPilot] 4.5.5,
the classic multiplayer gravity war game. It plays from the original block-based `.xp`
map files without changes. It is *not* network-compatible with the C XPilot client or
server; it uses its own UDP protocol (`docs/PROTOCOL.md`).

[IMPORTANT]
====
*Independent derivative port.* JXPilot is an independent port of XPilot 4.5.5 to
the JVM. The original XPilot authors (Bjørn Stabell, Ken Ronny Schouten, Bert Gijsbers,
Dick Balaska, and the many XPilot contributors) were *not involved* in this project
and do not endorse it. Please don't send them bug reports about JXPilot; open an issue
here instead.
====

Status: work in progress. The map/config parser, protocol, and map renderer/viewer are
done. The server simulation and networked gameplay are being built. See `docs/SPEC.md`
for the plan and milestones, and the user guide's
link:docs/guide/01-introduction.adoc#status[status table].

== Documentation

The *link:docs/guide/JXPilotGuide.adoc[JXPilot User Guide]* covers downloading and running the client
and server, network binding, every server option, the config and map file formats, every client flag,
and building from source. Each chapter reads on GitHub; the single-page HTML version is attached to
every release and published at https://awkay.github.io/jxpilot/.

== Downloads

Runnable jars (Java 25), the maps, and client applications with a bundled Java runtime for macOS,
Linux and Windows are on the https://github.com/awkay/jxpilot/releases[Releases page]. See the guide's
link:docs/guide/02-quick-start.adoc[Quick start].

[source,bash]
----
java -jar jxpilot-client-VERSION.jar --view-map maps/default.xp
----

== Building and running

Requires JDK 25 and Maven.

[source,bash]
----
mvn install                                   # build + test all modules
mvn -pl client exec:exec                      # map viewer (default.xp)
mvn -pl client exec:exec -Dclient.args="--view-map ../maps/planetx.xp"
mvn -Prelease verify                          # also build the release jars into dist/target/release/
----

== Playing from a checkout

The game client plays on a JXPilot server or on an original C XPilot 4.5.5 server (`xp://host:port`).
Build once, then run it from the compiled classes:

[source,bash]
----
MAVEN_OPTS= mvn -q -o -pl client -am test-compile
client/scripts/run-client.sh --connect xp://127.0.0.1:15345 --name Pilot   # C server
client/scripts/run-client.sh --connect 127.0.0.1:15345 --name Pilot        # JXPilot server
----

`client/scripts/xp-c-server.sh` runs the C server in Docker (image built by `tools/xpilot-ref/build.sh`),
e.g. `--map teamball --robots 4 --seconds 900 -- +restrictRobots` for a map with items and balls. Keys
are XPilot's defaults; kbd:[Esc] quits. See `docs/XPILOT-PROTOCOL.md` for what the C path supports.

== Project layout

* `common/`: map and config parsing, options, wall geometry, ship shapes, network protocol
* `server/`: game simulation and server
* `client/`: LWJGL renderer, HUD, input, networking
* `dist/`: release packaging (client launcher, runnable jars) and the guide's generated tables
* `maps/`: original XPilot maps, unmodified (see `maps/README.md`)
* `docs/`: spec, protocol, testing standard; `docs/guide/` is the user guide
